Countdown Timer

Vanilla JS · HTML + CSS + JS
  • CategoryMini-project
  • StackHTML, CSS, JS
  • FeaturesFlip digits, timezone
  • DependenciesNone

Drop-down Nav Bar

CSS Only · No JavaScript
  • CategoryMini-project
  • StackHTML, CSS only
  • AccessibilityKeyboard-friendly
  • DependenciesNone

A vertical dropdown navigation built without a single line of JavaScript. It uses :has() and hidden checkboxes to toggle submenus, respects reduced-motion, and works with keyboard navigation out of the box.

Glowific Social Icons

CSS Only · Neon + Reflection
  • CategoryMini-project
  • StackHTML, CSS
  • EffectNeon glow + mirror
  • PerformanceGPU-accelerated

A CSS-only treatment that gives social icons a neon glow and a mirrored reflection beneath them. Every effect is done with box-shadow, filter: drop-shadow(), and a ::after reflection — no images, no JavaScript.

  • CategoryMini-project
  • StackHTML, CSS, JS
  • FeaturesKeyboard support, history
  • DependenciesNone
